# First-node research

This workspace turns the vision into comparable, bounded candidate pilots. No land search, purchase, entitlement application, outreach, or development is started by creating these documents.

- [First-node brief](FIRST-NODE-BRIEF.md): what an integrated feasibility case must explain.
- [Site screen](SITE-SCREEN.md): how to compare candidate places without a misleading composite score.
- [Site dossier template](../templates/SITE-DOSSIER.md): consistent evidence for a candidate.

The [land department](../departments/land-and-location/README.md) leads place research. [Synthesis](../departments/synthesis-and-strategy/README.md) compares whole-node alternatives with other departments.
