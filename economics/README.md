# Economics workspace

This workspace connects enterprise activity and ownership to household outcomes. The [economics department](../departments/economics-and-household-finance/README.md) owns definitions and reconciliation; [capital and ownership](../departments/capital-and-ownership/README.md) owns financing and entitlement alternatives.

- [Accounting contract](ACCOUNTING-CONTRACT.md): entities, flows, definitions, and required checks.
- [Illustrative cash-flow bridge](ILLUSTRATIVE-CASH-FLOW.md): arithmetic explaining the scale of the founding examples.

There is no calibrated financial model or validated revenue forecast here yet. Future calculations should be reproducible, link every material input to evidence or an assumption ID, and compare complete household budgets with a stated alternative.
