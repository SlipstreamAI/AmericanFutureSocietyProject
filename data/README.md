# Data and provenance

No datasets are downloaded by the foundation setup. Keep source code, concise derived tables, metadata, and reproducible acquisition instructions in Git; keep bulky raw data and runtime state in the operator's designated external locations.

For every future dataset record: dataset ID; publisher; original URL; release/version; retrieval date; period; geography and spatial reference if applicable; unit; grain; population/coverage; methodology and uncertainty; license/use terms; transformations; responsible department; permitted storage location; and which findings/model inputs use it.

Do not commit credentials, private resident/applicant records, health data, bank records, raw private conversations, or restricted files. Use synthetic household records in public models. Public source data can still have terms or disclosure limits that must be respected.

Use the [source catalog](../research/SOURCE-CATALOG.md) for discovery and the [research method](../research/METHOD.md) for claims. Data availability is not evidence that a dataset is fit for a particular site decision.
