# Research departments

Each folder describes a specialist perspective, a consequential first deliverable, the evidence it needs, and the other departments it must connect to. These are research charters rather than permanent agent assignments. The operator chooses staffing, tools, and which work begins.

Start with the [vision](../vision/README.md), [status](../coordination/STATUS.md), and [research agenda](../research/AGENDA.md). A charter can be refined as the project learns; avoid multiplying departments before the work needs them.

## How integration works

Department research produces evidence and alternatives. [Synthesis and strategy](synthesis-and-strategy/README.md) compares whole-node cases and reconciles conflicts. Shared [assumptions](../research/ASSUMPTIONS.md), [findings](../research/FINDINGS.md), [decisions](../coordination/DECISIONS.md), and the [work log](../coordination/WORK-LOG.md) prevent separate specialists from quietly working on different versions of the project.

Agreement is not required. If evidence conflicts, record the competing claims, their sources, and what would distinguish them. Actual resident engagement and operator decisions remain distinct from agent analysis.
